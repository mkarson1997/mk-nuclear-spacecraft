# Pro Max Creative Frontend Skill

This directory publishes Mahmoud Karzoun's `pro-max-creative-frontend` skill package as an auditable source artifact for the MK Nuclear Spacecraft skills collection.

## Package

- `pro-max-creative-frontend-skill.zip` contains the complete submitted skill package.
- The package includes `SKILL.md`, its README, and four reference templates covering experience planning, inspiration principles, interaction feedback, and quality gates.

## Audit status

Before publication, the submitted ZIP was extracted and the Markdown files inside it were scanned for common credential, token, API-key, password and private-key patterns. No secret values or credentials were identified in the extracted submitted sources.

## Purpose

The skill is a reusable workflow for auditing and upgrading existing frontend products while preserving product logic and prioritizing domain-specific design, accessibility, performance, responsive behavior, RTL/LTR, restrained motion, and optional advanced graphics only when justified.

## Public-release note

This package contains source instructions only. It does not include credentials, runtime secrets, generated build artifacts, customer data, or deployment configuration.
